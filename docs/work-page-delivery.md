## 状态修复与数据边界

工具状态按调用 ID 配对。并行工具中一个结束，不再把其他仍在运行的命令覆盖为思考；自动审批保留正在执行的工具，缺少工具开始事件时仅显示检查权限。工具全部结束后显示思考，同时保留最近工具名称。会话结束或中断后，迟到的工具结束事件不再重新激活该轮次。

项目、模型、推理档位和轮次时间来自本机实际元数据，内部 `codex-auto-review` 不计入用户会话。步骤必须来自结构化计划；没有可验证计划时隐藏，不按工具数量推算完成百分比。

多会话数据分包发送，同一代次完整到达才替换显示；已开始发送的批次完整发送，尚未开始的批次只保留最新一份。新增只读工作信息回读，用于核对设备实际收到的数据。

## 长会话自动审批误报修复

`Welfare` 会话的当前轮次审批设置距离日志末尾超过 10 MiB；旧读取器只检查末尾 8 MiB，因此返回未知，而旧默认分支把未知判为人工等待，造成自动审批红闪。已用该真实会话复现。

审批元数据改为首次顺序建立索引、之后增量读取，不再受文件尾部距离限制；仅缓存审批元数据，最多 32 个文件、每文件 128 个轮次，并处理半行与文件截断。未知处理方不再触发人工等待；只有明确为 `user` 且非 bypass 模式才进入批准提醒。

同一真实长会话已正确读取到 `auto_review`，首次读取约 7.91 ms，增量读取约 0.64 ms。此处仅调整 HUD 提示，不修改 Codex 的审批策略、信任记录或审批结果。

该修复已通过 77 项主机测试并重启 daemon 生效；异步未回答问题的提醒仍是独立缺口，本次没有将异步工具返回直接当作人工等待。
