## 调整

移除总览页及其入口。短按从当前详情直接进入下一个会话或结果，最后进入时钟；时钟再短按返回会话并恢复自动选择。空列表、当前会话消失、只有历史结果时均有回退处理，不出现空白总览页。自动最短停留 8 秒、手动保持和完成卡展示规则继续保留。

待回答、人工审批和明确错误分别使用“待回答”“待审批”“执行失败”作为大字标题。实际工作状态与本轮耗时在下面一行小字显示；例如异步问题尚未回答但命令仍在运行时，显示大字“待回答”和小字“运行命令／本轮耗时”。正文继续显示真实未答问题或审批说明。

顶部按类别分别汇总：待回答是未答问题数量，待审批和错误是相应会话数量。多种类型并存时同时列出，不再统一写“待处理”。有全局提醒时暂时隐藏 Codex 品牌文字、电量和浏览序号，为分类标签留出空间；没有提醒时恢复。手动停留时钟页同样显示分类提示。类型未知的兼容等待状态显示“需查看”，不虚构成问题或审批。

本轮未改动已有问题 ID 跟踪、自动审批过滤、部分回答清除和新轮普通输入撤下旧提醒的规则，也未改动 `.9` 的蓝牙接收缓冲及任务栈修复。
